## 1. Framework

**0.85 (FACT):** `Src\Engine\WXCore\PostFilter`: `PostFilterManager` + factories for 5 filters (Bloom, Fade, Floodlighting, HeatVision, MotionBlur; `WXPostFilters.cpp:10–14`). Each filter calls `CompositorManager::addCompositor(vp, name)` on a compositor defined in a script (`WXPostFilter.cpp:56`, `PostFilter\media\*.material`, Cg).

**B (FACT):**
- `FairyCore\Core\PostFilter\FairyPostFilterManager.cpp`: `registerFactory`, `createPostFilter`, `getPostFilter` (by name or by mask), `PostFilter::setParameter/getParameter` (string key/value). 27 factories carry `Fairy::<Name>PostFilter::Factory::checkEnable` (material-availability check): Bloom, ColorLUT, ColorMask, ColourControl, ComplexBlur, DLAA, Dof, Drunk, EnergyWaveMask, FXAA, FXAAQuality, Fade, FadeColor, FinalPass, Floodlighting, GaussianBlur, GodRays, HeatHaze, HeatVision, HeightFog, LightMove, MotionBlur, NewHDRBloom, RadialBlur, ScreenRain, ScreenSplit, TransSceneEffect; plus the legacy **HDR** filter (builder `FUN_1801ac060`) and the **SceneRender** pipeline filter (`FairyRenderPipeline\FairySceneRenderPostFilter.cpp`) = 29 compositor-based filters + render nodes.
- **No compositor scripts**: every filter builds its `Ogre::Compositor` in code (B OgreMain has dropped `CompositorScriptCompiler`, 45 exports only in A — `Docs\evidence\binlineage\expcmp.txt`). Typical builder (`FUN_1801b3d50`, HeightFog): `createTechnique`; texture def `scene_buffer` with **reference** (`+0x20 = "SceneRender"`, `+0x40 = "scene_buffer"`); `setInputRTAliasName("rt_input","rt_output")`; one target pass (`setOutputNameAlias("rt_output")`, input mode 0) with one quad pass (`setType(3)` = render quad, `setMaterialName`, `setInputAlias(0,"rt_input")`, `setIdentifier(n)`); `setOutputRTAliasName("rt_output","rt_input")`. INF: the chain ping-pongs two shared RTs; each filter reads `rt_input`, writes `rt_output`.
- Pass identifiers let the filter's listener push constants when the material is set up (e.g. NewHDRBloom: 0x323 → `threshold`, 700–702 → `sampleScale`, 500 → `bloomColor`, 600 → `bloomColor`+`exposure`; GodRays: 800 → `SunRT` texture + `sunPos_decay_exposure`, 0x322/0x323 → `fStrength`), FACT `FUN_180198780`, `FUN_1801b8240`.
- TextureDefinition fields written by builders (B layout, FACT offsets): +0x60/+0x68 width/height (size_t), +0x70/+0x74 width/height factor (float, relative to viewport), +0x78..+0x80 pixel-format vector, +0x90..+0x98 flags, +0xa8 camera name. Format values (OGRE 1.2 enum from `OgrePixelFormat.h`; INF that B kept the numbering): 10 `PF_R8G8B8`, 12 `PF_A8R8G8B8`, 22 `PF_FLOAT16_RGB`, 26 `PF_X8R8G8B8`, 32 `PF_FLOAT16_R`, 33 `PF_FLOAT32_R`.
- Required OgreMain compositor extensions (FACT, B-only methods in `ogre_api_gap.tsv`): `CompositionTechnique::{set,get}{Input,Output}RT{Alias,Real}Name`, `setCompositorLogicName`; `CompositionTargetPass::{setOutputNameAlias, setOutputMode, setDSReplace, setFogEnabled, setForceSwap, setVisibilityMaskExclude}`; `CompositionPass::{setInputAlias, setRenderQueuePair, setCustomType, setQuadCorners/FarCorners, setClearRect}`; `CompositorInstance::{getTextureInstance, getRefCompositorInstance, swapRTFlag, queueTargetOp}`; `CompositorChain::{_compileOutPutTargetOperations, getPreviousInstance, getNextInstance}`; `CompositorManager::{getPooledTexture, registerCustomCompositionPass, registerCompositorLogic, setCustomMask}`; `TextureUnitState::setCompositorReference` (for `content_type compositor …`).

**Chain order (FACT `FUN_18000e530`, render init):** Floodlighting, Fade, HDR, ComplexBlur, GaussianBlur, HeatHaze, TransSceneEffect, FXAA, NewHDRBloom, ColorLUT, HeightFog, GodRays (created via `FUN_18007af90` in this order; availability flags at renderer+0xbc, +0xb8, +0xc0, –, +0xc4, +0xc8, +0xd4, +0xe4, +0xec, +0xf0, +0xf4). The render-settings table at 0x1803a1620 has 14 entries: Floodlighting, Fade, HDR, ComplexBlur, GaussianBlur, HeatHaze, TransSceneEffect, ColorLUT, ColorMask, Drunk, FXAA, NewHDRBloom, HeightFog, GodRays (FACT, read from `.data`). SceneRender is first (scene into `scene_buffer`) and FinalPass last (`FrameCopy`, target-pass output mode 1 = viewport, `FUN_1801b6550`).

**SceneRender render nodes (FACT `FairySceneRenderPostFilter::addRenderNode/addRenderTextureDef/createRenderPassDef/addRenderTargetPassDef`, `FairyRenderNode.cpp`):** `defRenderNode_SceneDepth` (`depth_buffer`, scheme `Depth`), `defRenderNode_SceneDepthForWater`, `defRenderNode_ShadowMap` (node 4, 03 §2), GenSSAO (below), FinalPass. The technique is rebuilt when a node is toggled (`FUN_18015eec0`).

**Enabling and events (FACT):** filter on/off = `FUN_18007bb30(chain, name, bool)`. `FUN_180016fe0` handles `VARIABLE_CHANGED(_IMM)` events for `View_*` keys and calls renderer vtable slots: `View_FullScreenLight`→+0x2d8 (Floodlighting), `View_HDRFilter`→+0x2e0 (**empty stub in the original DLL**; client_GL's `patch_hdr.py` cave enables NewHDRBloom), `View_Fanhunjiao`→+0x5b8 (FXAA), `View_HumanLightmap`→+0x310, `View_TextureFiltering`→+0x2c8, `View_ObjectMove`→+0x2d0, `View_UpdateQuality`→+0x590, `View_EffectLevel`→+0x598, `View_Weather`→+0x318, `View_WalkEffect`→+0x330. Values read at start-up do **not** raise the event (KET-QUA-PHA1 §9) — must be fixed in CY-Source. Debug/GM names printed by `debugpostfilter` (`FUN_18000cc20`): `Scene_SetSceneLUTParam("LUT_00gao.png")`, `Scene_SetGodRaysEnabled`, `Scene_SetHDRFilterEnabled`, `Scene_SetPostFilterEnabled`, `Scene_SetPostFilter_Death`, `Scene_SetSceneNewHDRBloomEnabled(TRUE, TRUE, FALSE)`, `Scene_SetHeightFogEnabled`, `Scene_HeatHazeFilter`, `*Scene_GaussianBlurFilter(true,"1.0")`, `*Scene_DrunkFilter(true,"1.0")`.
**Per-scene parameters (FACT `FUN_180018540`):** after loading `<scene>.Scene`, for filters HDR, NewHDRBloom, HeightFog, GodRays the loader calls filter vtable +0x28 with the scene name → readers `FUN_1801ade30` (.hdr), `FUN_1801981b0` (.newhdrbloom), `FUN_1801b4e20` (.hfog), `FUN_1801b7d40` (.godrays), `FUN_180194500` (.bloom): file looked up in a temporary `#TEMP#` FileSystem location for the scene folder, then resource group `Scene`; built-in defaults when absent (05 §2). Login/select scenes (param < 0) force `View_HDRFilter` off.

## 3. Per-scene file formats used by post-filters (FACT: reader read order + setParameter name→offset)

- `.newhdrbloom` (34 B, 548 files): `f32 Intensity, f32 Threshold, f32 SoftKnee, f32 Exposure, u8 UseHDR, u8 UseAutoExposure, f32[4] BloomColor` (read order `+0x60,+0x64,+0x68,+0x6c,+0x70,+0x71,+0x50`; names from `FUN_180198f80`). Missing file → (0, 1.0, 0.5, 0, 1, 1, white). **Correction:** earlier notes (KET-QUA-PHA3 §2, task brief) called f0 "threshold / f1 exposure / f2 intensity"; the decompile shows f0 = Intensity, f1 = Threshold, f2 = SoftKnee, f3 = Exposure. Caution: 522 of the 548 files were written by `hdr_tune.py` on 2026-09-03 (value `3.0 0.65 0.35 0 0 0`); originals are in `*.newhdrbloom.hdr-bak`.
- `.hdr` (20 B, 168 files): `KeyValue, LimitedLuminance, GaussianMultiplier, GaussianOffset, GaussianDev` (read into +0x320…+0x330 = the setParameter offsets of `FUN_1801aef30`); defaults (0.5, 0.5, 1.0, 0, 3.0); data ranges 0–0.88, 0–1, 0–2, −1–1, 1–5 (`scene_binfields.tsv`).
- `.hfog` (64 B) and `.godrays` (12 B): see 05 §2.

## 4. Spec for CY-Source (order by beauty/effort)

1. **Compositor extensions + chain manager** (all methods of §1) and the **render-node framework** (SceneRender with nodes ShadowMap, SceneDepth, SceneDepthForWater, GenSSAO, FinalPass). Config-driven enable at start-up; filters toggled at run time by name. (≈2 weeks)
2. **NewHDRBloom** with linear-space conversion, FP16 mip chain, soft-knee threshold, ACES tone map, optional auto exposure from the 1×1 luminance chain; per-scene `.newhdrbloom`. (≈1–1.5 weeks)
3. **FXAA / FXAAQuality / DLAA** (materials exist; 1–2 days each).
4. **HeightFog** (needs SceneDepth or INTZ) + EnvKey time-of-day parameters. (≈1 week)
5. **GenSSAO** node + `ssao_buffer` binding at s12. (≈1 week)
6. **ColorLUT, GodRays, DoF** (≈1 week together); gameplay filters (blur family, heat haze, drunk, fade, rain, split, energy wave, trans-scene) 1–2 days each.
7. Optional beyond B: the EnvKey grading filters (ColdWarmMask/EnhanceConstrast/OverlayImage).

Acceptance: log line per enabled filter; image diff vs client_GL at Tô Châu with FXAA+NewHDRBloom (same `.newhdrbloom`); 1440p ≥ 60 fps on RTX 2060 with FXAA+HDR+HeightFog+SSAO (doc 03 gate E3).
