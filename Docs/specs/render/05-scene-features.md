## 1. How a scene references its beauty data (FACT)

- `<scene>.Scene` (Fairy `SceneSerializer`, `FUN_1801613c0`): `<Scene formatVersion>`, `<Terrain filename>`, `<ModelMaterialScheme scheme>` (6 files), **`<SkySphere enabled filename="x.skysphere" objectname="#FairySkySphere"/>`** (344 occurrences), `<MovieData filename>`, then `<Object>`s. **EnScene** is an object: `<Object name="#FairyEnScene" type="EnScene"><Property name="config_file" value="X.EnScene"/><Property name="enabled" value="true"/>` (190 `.Scene` files) loaded by `Fairy::SceneInfo::load` (`FUN_1800452a0`, messages "EnScene : successfully load EnScene config file '…'", "skysphere error : failed to open skysphere config file resource'").
- Render scene loader `FUN_180018540`: toggles `#FairySkySphere` by its `enabled` property; reads the `Enviroment` object (0.85-compatible properties `ambient, fog.mode, fog.colour, fog.exp density, fog.linear start/end, weather.*` — FACT same literals in 0.85 `WXEnviromentObject.cpp`); then post-filter scene files `<scene>.hdr/.newhdrbloom/.hfog/.godrays` (02 §1).
- Counts (FACT `scene_features.json`): `.newhdrbloom` 548 (522 generated by us, 02 §3), `.hdr` 168, `.hfog` 7 (FengYun_*, cy4_*), `.godrays` 0, `.bloom` 0, `.skysphere` 305, `.EnScene` 197. Combinations per scene: `.newhdrbloom+.skysphere` 268, `.EnScene+.hdr+.newhdrbloom` 129, `.newhdrbloom` only 57, `.EnScene+.newhdrbloom` 51, `+.hfog` 7…

0.85 has only `SkyDome` (`WXSkyDomeObject.cpp`: material, curvature, tiling, distance, x/y segments, draw first), `Enviroment`, `TerrainLiquid` — FACT; no SkySphere, EnScene, EnvKey, FakeLight, HDR files, height fog or dynamic bones.

## 3. `.skysphere` (305 files, XML, `Fairy::SkySphereObject::loadFrom` `FUN_1800f1120`, `FairySkySphere*.cpp`)

Tree (FACT, `scene_xml_inventory.tsv`): `SkySphere` → `SkyHeight(enable_fixed_height, fixed_height)`, `EffectLOD/ParticleLOD(min/max_distance)`, `SkySunshine(distance, texture_sunrise/sunset, rotate_axis, rotate_angle, start_time, duration)`, `SkyMoon(distance, direction) → DateConfig(date 0..30, texture) → AlphaKeyList → KeyAlpha(time, alpha)`, `SkyStar(star_count, star_size, radius, intensity, flicker_speed, start/end_colour)`, `SkySphereLayers → SkyLayer(name ∈ background/far_cloud/fog/mountain/near_cloud, distance 2000–5000, pitch_start/end, rotate_speed, texture_count)`, `SkyWeathers(current_weather) → Weather(name) → SkySphereTextureGroups → TextureGroup(<layer>_texture, <layer>_wrap, AlphaKeyList)`, `SkyEnviromentList → EnvKey(time 0..1, ambient, fog, sky_fog, fog_near/far_distance, light_one/two(+_specular, _intensity), actor_light_*)`, `SkyEffectParams(show_moon/star/sun_flares/sunshine) → Effect(name Thunder|WeatherParticle) → Parameter(name,value)`.
Rendering (FACT): layers are sky-sphere meshes blended with `SkySphereLayerBlend_{One,Two,Three}Texture_VS_1_1_hlsl / _PS_2_0_hlsl` (`MaterialFolder\SkySphereLayer.program`, `BLEND_TEXTURE_NUM`), stars `SkySphere/FixedStar` with `StarVP/StarFP` (`FixStar.hlsl`, custom constants 100/101), sunshine `Fairy::SkySunshine`, thunder `SkyThunderEffect` (min/max interval, duration, sound file, min/max saturation/brightness/exposure, effect list, start/end time — `FUN_1801d9ff0`).

## 6. Lights

- `Light` objects (7,330; FACT `scene_objects.tsv`): `position, diffuse, specular, range (1000 typical), attenuation.constant/linear/quadric, direction, intensity, end brightness, cast shadows (156 true), type spotlight (10)` → up to `MAX_LIGHT_NUM 3` per object via the light-array auto constants.
- `FakeLight` objects (4,362, **not in 0.85**): `position, orientation, scale, size 1.4–1.7, diffuse, intensity, begin/end brightness` → rendered as screen-space light volumes with `Mtl_FakePointLight(_DSIntZ)` (`FakePointLight_vs.hlsl`, `Model_FakePointLight_ps.hlsl`, needs scene depth) and scaled by EnvKey `fake_point_light_intensity` (INF from names). Big visual win for night/indoor scenes at low cost.

## 7. Dynamic bones — `.dynbone` (26 files, 2024–2026 costumes/hair/weapons)

XML (FACT): `EntityDynamicBones` → `DynamicBones → DynamicBone(Bone, Damping 0.2–0.6, Elasticity 0–0.03, Stiffness 0–0.85, Inert 0.1–0.3, Friction 0.1, Radius 0–2, Force (0,−30..0,0), UpdateRate 1–60) → CurveParams(DampingACParam, ElasticityACParam, StiffnessACParam, InertACParam, FrictionACParam)`; `Colliders → CapsuleCollider(Bone, Center, Orientation, Radius 6–30, Height 40–100, Invert)`; `Effects → Effect`. Loader `FUN_1801ce6e0` (`<model>.dynbone` next to the mesh), parser `FUN_180230940`. INF: parameters mirror Unity "Dynamic Bone" (damping/elasticity/stiffness/inert + capsule colliders), simulated per frame on skeleton bones after animation.

## 8. Spec for CY-Source

1. `SceneInfo` loader for `<SkySphere …/>` and `#FairyEnScene` objects; per-scene file lookup (`#TEMP#` then group `Scene`) with the defaults above.
2. **EnScene** renderer (dome with Mie term, cloud layers with scattering/rim, ring clouds, sun/moon/stars, lens flare) + **EnvKey** interpolation by time of day and region, feeding SceneManager (ambient, PBR ambient, actor lights, sky-dome ambient, fog, brightness), shadows and HeightFog. (≈3–4 weeks)
3. **SkySphere** renderer (5 blended layers, sunshine, moon phases by date, stars, weather sets, thunder). (≈2 weeks)
4. **Water** (reflection/refraction/mirror RTs, depth node, ShaderParams, PBR water templates). (≈3 weeks)
5. **FakeLight** (≈1 week) and **dynamic bones** (Verlet chain + capsule colliders, ≈2 weeks).

Acceptance: 10 reference scenes (doc 03 gate E3) at fixed times of day; sky/cloud/water within SSIM 0.95 of client_GL; no scene file parse warnings.
